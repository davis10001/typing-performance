# Centrally provided benchmark content

No ranges, averages, percentile statements, or ranking claims have been defined by the implementation team. The result UI intentionally shows a source-review notice instead of a benchmark band.

When the central product/content owner supplies the reviewed dataset and copy, add a versioned definition in this folder with source URL or document ID, population/method, date, score bands, and review owner. Link that file from `release/approvals.json` and only then implement the band. Do not infer bands from competitor websites or unattributed “average WPM” claims.
