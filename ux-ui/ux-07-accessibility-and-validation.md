# 07 无障碍与验收

## 验收

- Tab 顺序为导航→时长→开始→测试输入→结束→结果操作；焦点可见且到时进入 Result 标题。
- 测试文本错误/倒计时不是每个字符都用 aria-live 播报；完成时一次播报成绩摘要。
- 正确/错误/当前 token 不仅用颜色；所有文字和交互控制满足 WCAG 2.2 AA 对比度和键盘可达性。
- 375px、768px、1280px 宽度下没有水平滚动或遮挡主输入；桌面与移动真实完成一次测试。
- 用键盘、读屏抽检（VoiceOver 或等价工具）和主流浏览器手动验证 UXF-01–05。
