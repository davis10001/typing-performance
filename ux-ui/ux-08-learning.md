# 08 学习体验 · 已按原核心实施

依据：[Learning PRD](../product-requirements/prd/prd-10-learning.md)。模式：Operate。继承现有界面的视觉与控件规则，不进行品牌重设计。

| 页面 | 用户任务 | 主要内容/操作 |
|---|---|---|
| P-LEARN `/learn` | 选择自动安排或课程学习 | Continue practice、Courses；已有进度明确仅在此浏览器 |
| P-PRACTICE `/learn/practice` | 连续练习当前目标键 | 原引擎练习文本、目标键/可用键、键盘指法、完成后继续 |
| P-COURSES `/learn/courses` | 查看学习顺序与选课 | 原课次、当前学习键、完成/锁定状态、原学习者类型选择 |
| P-LESSON `/learn/courses/[lessonId]` | 完成或复习指定课 | 课名/按键、原课文、指法、结果、Repeat/Next lesson |

配置、运行状态、主要动作在同一顶部区域内切换，避免散落。选中态使用 Highlight 文字色，不使用白色色块。学习计时与完成条件由对应原方案决定；不增加测速倒计时。

首次进入提供简短指法说明并直接开始原方案；不添加视频或新的课程层级。结果显示原计分和下一步；不要把 confidence 百分化包装成“掌握率”。已完成全部可用键/课时提供继续练习或复习，具体规则按原方案，不伪造新等级。

异常状态：失焦/暂停有可见返回操作，保留焦点顺序；存储不可用显示“Progress could not be saved on this browser”；未知版本保留原进度并解释不可读取；清除由用户确认且仅清学习数据；陈旧标签页提示重新载入进度。未审查素材不得呈现可开始状态。

桌面与 375px 小屏核验：内容不横向溢出、课次信息可读、焦点可见、主要操作触控目标合适。逐键视觉反馈不逐键广播读屏；仅播报轮次完成/重要状态。手机软键盘能力须实测后说明，不仅凭页面响应式就宣称完整练习支持。

页面显示来源致谢及对应版本源码入口，放在说明/页脚。课程用语必须准确说明所含内容（当前候选不含完整数字/标点训练）。

## 实施核验 · 2026-10-12

`/learn` 内两个入口并列，不增加额外功能层级；导航原 Lessons 位置改为 Learn。练习顶部把模式/目标键或课次/新键与重新开始动作收在同一区域。选中态使用 Signal/Highlight 文字颜色，无白色色块。连续练习和固定课程共用展示/指法组件，但分别保留 Keybr 与 KTouch 输入及结果语义。

Playwright 已覆盖 1280/768/375px、Firefox/WebKit 桌面，无横向溢出和 axe 阻塞项；真实页面截图另经浏览器检查。移动软键盘不是 V1 完整练习承诺，产品仍以桌面实体键盘为准。
