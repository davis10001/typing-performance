# 05 安全与运行

P0 无登录、无权限数据库。浏览器禁止粘贴和拖放写入测试答案；页面隐藏/失焦和极端输入只作为 anomaly flag，不作为安全认证。不得将“前端防粘贴”描述为防作弊保证。

最小化原则：测试完成前不发送输入数据；分析仅发送白名单匿名属性；错误监控须 scrub URL query、输入内容和任何可识别值。Local history 提供清除入口，隐私页说明其浏览器本地范围。

运行：使用 request ID 关联服务端错误（P1），前端捕获未处理错误并向 Sentry 类服务发送脱敏堆栈。监测 Web Vitals、测试开始/完成、客户端存储失败和 JS 异常。依赖不可用时：测试和本地结果仍可用，分析/错误上报静默降级。

P1 仅由服务端持有服务角色密钥；公开环境变量不得包含可写特权。生产发布前需完成安全 header、CSP 可行性评审、隐私政策、Cookie/分析同意要求适用性评审。
