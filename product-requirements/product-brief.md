# Typing Performance · Product Brief

**版本**：1.1 · **更新日期**：2026-10-11 · **状态**：已确认的开发输入（P0 测速基线 + Learning V1 扩展）

2026-10-11 范围更新：用户已确认独立学习栏目，包含 Keybr Guided 连续学习和 KTouch 固定课程，优先复用原规则与源码并接受相关开源义务。以下“首版/P0”保留历史测试范围；当前新增实施范围以 [Learning V1](./prd/prd-10-learning.md) 为准，覆盖原先将学习全部延期的安排。

## 1. 执行摘要

Typing Performance 是面向英语市场的轻量 Web 产品，让匿名用户在 1 / 3 / 5 分钟内完成打字测试，立即理解 WPM 和准确率，并方便地重测。它不复制完整课程平台，也不止做一个测速皮肤；首版验证 `搜索入口 → 完成测试 → 理解结果 → 重测` 是否形成闭环。

## 2. 问题与依据

成熟市场的头部需求集中在 `typing test`、`typing practice` 与 `typing game`，但这些大词 KD 很高，适合作为市场地图而非新站首攻词。调研中，Timed Test（1/3/5 分钟）与 WPM 基准解释同时具备搜索量、较低/中等 KD、垂直中小站可排位和同一产品闭环；证书和 KPH 属于后续自然延伸。

用户目前通常只能得到一个分数，无法判断成绩是否有意义、是否改善，也缺少低摩擦的标准化重测入口。该产品以“结果解释和下一步”为差异，不承诺在首版提供课程或真实人群百分位。

## 3. 目标用户与场景

| 用户 | 场景 | 预期结果 |
|---|---|---|
| 普通个人 | 想知道自己打字有多快 | 获得可靠 WPM、准确率和可解释的水平区间 |
| 学生/学习者 | 练习后验证进步 | 以固定时长重复测试并看到本机最近记录 |
| 职场用户 | 评估效率并发现改进方向 | 完成快速测试，进入结果解释或后续练习 |
| 数据录入求职者（P1） | 需要职业指标 | 获得 KPH / CPM / WPM 测试结果 |

## 4. 方案与价值

**核心循环**：Test → Understand → Improve → Retest。

首版实现其中前 3 个可执行环节：Timed Test、结果/基准解释与重测；Improve 在 P0 是指向解释与重测，在 P1 才扩展为弱键练习。相较替代品：Typing.com 强在课程，Keybr 强在自适应练习，Monkeytype 强在极简测速；本产品把标准化测试与可理解的表现解释放在一个不登录的路径中。

## 5. 首版范围

**包含**：英文文本、1/3/5 分钟定时测试、客户端计分、结果页、可解释的静态 benchmark band、Average WPM/Speed SEO 页面、本机最近历史、基础 SEO 与匿名事件。

**不包含**：账号、云端历史、真实 percentile、完整课程、教师后台、多人竞技、排行榜、广告投放逻辑、证书、KPH/Data Entry（均在后续阶段）。

## 6. 目标与衡量

| 目标 | 指标 | 首版判定 |
|---|---|---|
| 验证搜索到测试的价值 | `test_start_rate` | 上线后按渠道建立基线；不预设虚假目标 |
| 验证核心体验 | `test_completion_rate` | 按时长建立基线，并排查异常中断 |
| 验证解释与回访 | `result_retest_rate`、`return_visit` | 观察结果页后重测与 7 日回访趋势 |
| 验证 SEO 可见性 | 已收录公开页、非品牌自然点击、目标页排名 | 通过 GSC 按周追踪 |

## 7. 假设、依赖与风险

| 项目 | 说明 | 验证/缓解 |
|---|---|---|
| 假设 | 长尾 Timed Test 与 Benchmark 意图可导入同一产品 | 上线后以按入口的开始/完成/重测漏斗验证 |
| 依赖 | 英文测试文本拥有可用许可 | 仅使用自写、公共领域或明确许可文本并保留来源 |
| 风险 | 低 KD 不能保证 SERP 机会 | 以真实 SERP、收录与排名复核，不以 KD 单独决策 |
| 风险 | 静态 benchmark 容易被误读为人群百分位 | 显示为说明性区间，提供来源；不展示 percentile |
| 风险 | 输入或异常事件导致不可信成绩 | 客户端使用实际时间、禁止粘贴并记录中断；不在 P0 做“认证” |

## 8. 进入 PRD 的结论

继续进入：首版范围与待验证假设足够清楚。产品结论是“验证 Typing Performance / Test + Result Interpretation”，不是宣称整个打字赛道已经被证明值得长期投入。
