# 02 用户与旅程

## 用户与 JTBD

普通个人想知道成绩；学习者想以固定条件复测；职场用户想理解效率。P0 的唯一角色为匿名访客；P1 才增加证书申请者和数据录入测试者。

| ID | 进入条件 | 主流程与价值结果 | 异常/恢复 |
|---|---|---|---|
| UJ-01 快速测试 | 从首页或 Timed Test 页面进入 | 选定预设时长→准备/倒计时→输入→自动完成→看到成绩 | 提前刷新/离开：本次不生成完成成绩；重新开始 |
| UJ-02 解释成绩 | UJ-01 完成 | 查看 WPM、Raw WPM、Accuracy、Errors、时长与 band→进入解释页或重测 | benchmark 内容不可用时，仍显示原始成绩并显示说明不可用 |
| UJ-03 切换复测 | 结果页或本地历史存在 | 选择 1/3/5 分钟→新测试→比较最近记录（仅同浏览器） | LocalStorage 不可用：继续测试，不承诺保存历史 |
| UJ-04 SEO 内容转化 | 从 Average WPM/Speed 页面进入 | 阅读独立解释→选择测试时长→进入 UJ-01 | JS 被禁用时可读取正文与 CTA，交互功能提示需要浏览器脚本 |
| UJ-05 本地历史 | 至少完成一次测试且存储可用 | 查看最近有限记录→选择重测 | 用户可清除；清除后不可恢复 |

测试中若失焦或页面隐藏，P0 仅记录客户端异常状态，不阻断普通结果；结果页不得将其标成 Verified 或 Certificate。
