# 07 非功能需求

| ID | 要求 | 可验证阈值/方法 |
|---|---|---|
| NFR-01 输入性能 | 打字不因全页重渲染而卡顿 | 支持的桌面和移动浏览器中，连续输入不出现肉眼可见阻塞；以 INP p75 < 200ms 为上线目标 |
| NFR-02 页面性能 | SEO 入口快速可用 | 生产真实用户 LCP p75 < 2.5s、CLS p75 < 0.1；性能预算纳入 CI/Lighthouse smoke |
| NFR-03 正确性 | 成绩可重现 | 计分纯函数覆盖正常、Backspace、零输入、边界时间及错误字符用例；同一输入得到同一结果 |
| NFR-04 隐私 | 最小化采集 | P0 默认不要求账号；不得传输原始文本、逐击键、姓名或不必要身份数据；提供本地清除入口 |
| NFR-05 可用性 | 异常不产生误导性完成记录 | 刷新/关闭时不保存 completed result；LocalStorage 失败不阻断主流程；监控前端异常 |
| NFR-06 兼容性 | 支持现代浏览器 | 最新两个主版本 Chrome、Safari、Firefox、Edge；375px 宽移动视口及桌面键盘可完成测试 |
| NFR-07 无障碍 | 键盘和读屏用户可操作 | 全流程可键盘操作；可见焦点；错误/计时变化不高频打断读屏；满足 WCAG 2.2 AA 的可行项 |
| NFR-08 SEO | 内容不依赖客户端水合 | 公开页服务端/静态输出 title、description、H1、正文、canonical；sitemap 和 robots 在生产可访问 |
