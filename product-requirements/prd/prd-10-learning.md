# 10 学习模块 · Learning V1

**版本**：1.2 · **日期**：2026-10-12 · **状态**：功能实现与自测完成；生产发布门禁未关闭。

本文件是本轮学习功能的产品基线。用户已确认两个并列入口、成熟方案优先、允许修复有证据的严重缺陷，以及接受相关开源义务、优先直接复用原代码。原 P0 测速需求继续适用；本文件通过 PD-08 扩展后续实施范围，不把新增功能追记为已完成的 P0。

## 1. 目标与边界

学习栏目是一个连续页面，依次提供：

- **Continuous practice（连续学习）**：进入 `/learn` 即显示并可直接输入；系统依据表现安排下一轮内容，随能力逐步增加练习范围。遵循 Keybr Guided。
- **Courses（固定课程）**：连续练习下方直接展示 15 课；用户可自由打开任意一课学习或复习。课文、纠错和通过规则仍遵循 KTouch，访问方式固定使用其 Experienced 的全课可访问路径。
- **学习说明**：页面底部用可索引的服务器渲染文本说明两种练习的适用场景、范围与本机数据边界。

“从简单到复杂”指原方案中的按键范围和练习要求演进。不要求自动从单字母进入单词、句子或文章；不增加该转换算法。学习与测速是不同活动，学习得分不写入测试历史或与测试 WPM 混排。

V1 承接现有英语网站、匿名访问与本机存储方式；先支持桌面实体键盘、英文 QWERTY。小屏可阅读课程和进度，移动软键盘是否支持完整练习须在输入适配阶段验证后明确提示，不宣称未经验证的兼容性。目标不是 K-12 教学管理；视频、教师后台、账号、云同步、排名、证书及每日任务不在本轮。

## 2. 采用来源和优先级

| 部分 | 依据 | 固定基准 |
|---|---|---|
| 连续学习 | [Keybr](https://github.com/aradzie/keybr.com) Guided 实现 | `05a37bc5265f65ff538c59c613db29442f345d51` |
| 固定课程机制及候选素材 | [KTouch](https://github.com/KDE/ktouch) | `a3f57d03e6c14956378af1176eef3404430c773e` |
| 课程质量准则 | [KTouch 课程编辑说明](https://docs.kde.org/stable5/en/ktouch/ktouch/extending.html) | 已教字符范围、目标字符练习、原课次顺序 |

证据优先级：锁定版本源码与对应测试 > 同版本实际行为 > 官方说明。源码与帮助页不一致时记录差异，以源码和可复现行为为准。官网当前部署版本不一定等于仓库版本，不宣称两者完全相同。

**不自创规则**：不得自行决定字母顺序、95%/连续三次等通关条件、错误权重、能力遗忘周期、强制复习频率、课文随机化或跨模式掌握度兑换。所有改变教学结果的数值与行为须有源码出处及一致性用例。

## 3. 来源审查已确认的事实

Keybr 锁定版本默认：Guided 模式、目标速度 175 CPM、真实单词优先开启、按键盘顺序选字母关闭、recoverKeys 关闭、大写与标点为 0、每词重复一次。原 Guided 源码已确认至少包含 6 个字母，默认按原模型频率排序；符合范围的真实候选不足时会补充生成词，不能宣传为全是真实单词。默认解锁及目标键选择使用历史最佳 confidence，而不是自行设定的最近三轮准确率。具体初始字母须从锁定模型解析，不抄旧帮助页列表。来源与细节见来源审查。

KTouch 官方手册记载默认门槛为 98% 准确率与 180 CPM；上线实现必须进一步核对锁定版本的计分、严格/非严格比较及配置来源，不能直接套用我们测速的计分公式。

当前候选 `us.xml` 与 `gb.xml` 均为 15 课。美式课第 2–7 课存在超出已教范围的字符；英式课最后一课声明全部大写字母，但 Q/X/Y 未在正文出现。两个文件自身均未发现许可证声明；这不等于无许可，也不能仅凭软件 GPL 标签断定所有素材权利已核实。完整目录、哈希与问题见 [来源审查](../research/learning-source-audit-2026-10-11.md)。

因此选择问题最少且只含字母/空格/换行的 GB 课程，保留 `sourceLayout=gb`；转换时仅在最后一课追加缺失的 `Q X Y`。原文件、原哈希、修复记录及转换产物版本均保留。文件级许可映射仍是生产发布门禁，不能因功能实现而视为已关闭。

## 4. 用户旅程

| ID | 流程 | 完成标准 |
|---|---|---|
| UJ-06 连续学习 | Learn → 直接输入首轮 → 查看目标键/表现 → 下一轮 | 下一轮由原 Guided 规则选取；用户可退出后继续 |
| UJ-07 课程学习 | Learn 向下浏览 → 任选课次 → 练习 → 结果 → 重练/下一课 | 15 课始终可选；未通过不误标完成；计分与输入语义不变 |
| UJ-08 恢复/清除 | 再次访问 → 恢复已完成进度，或选择清除 | 明确仅此浏览器；清除不影响测速历史；失败不假装成功 |

课程切换不暗中改变连续学习的能力状态。学习栏目可记住最后使用入口，但不得因此替用户完成课程或解锁按键。

## 5. 功能需求

| ID | 要求 | 验收条件 |
|---|---|---|
| FR-L01 学习入口 | Learn 为单页三段式结构 | 首屏直接连续练习，下方为可自由选择的 15 课与学习说明；不再设置额外的模式选择层 |
| FR-L02 Guided 初始化 | 用锁定版本原默认与内容资源启动 | 空进度生成结果满足原字母范围、长度与词库规则；不强制改成 F/J |
| FR-L03 Guided 适配 | 收集原算法需要的有效样本，直接复用原判断 | 同一历史与配置得到相同目标键、可用键集合及解锁决策 |
| FR-L04 Guided 连续练习 | 本轮完成后准备下一轮，允许重复/退出 | 不因 UI 渲染、重进页面或重复回调多记一轮；中断不伪装完成 |
| FR-L05 固定课程 | 显示课程顺序、课名、新键及完成状态 | 对照来源目录逐项一致；原文不被随机替换；布局标识准确 |
| FR-L06 课程通过 | 固定使用 KTouch Experienced 全课可访问机制 | 任意课次可直接进入；原配置、输入记录和通过边界不变；不伪造逐课解锁进度 |
| FR-L07 输入与指法 | 使用适合学习的键盘提示与输入反馈 | 退格、错误、换行、失焦、暂停按各引擎原语义实现；明确焦点；粘贴不成为有效学习样本 |
| FR-L08 结果解释 | 显示本轮表现和下一步 | 有依据地显示新键/目标键；不把 Keybr confidence 写成统计置信度或统一“掌握百分比” |
| FR-L09 本机进度 | 保存恢复所需记录及来源版本 | 刷新后恢复已完成进度；新旧规则不混算；异常存储有可见提示 |
| FR-L10 清除学习数据 | 单独清除学习记录 | 用户确认后仅清除学习命名空间；测速历史保留；失败可重试 |
| FR-L11 来源及开源 | 交付源码、许可证、第三方声明和改动记录 | 使用者能获取所部署版本所需的相应源码；链接不是只指向未修改的上游仓库 |
| FR-L12 内容和规则版本 | 各轮绑定模式、规则、内容与键盘版本 | 更新不覆盖旧课程 ID；不兼容数据不被静默迁移或清零 |

## 6. 状态与数据规则

页面层描述：准备 → 练习中 → 暂停/完成；离开当前轮为中断。实际输入、暂停恢复与完成判定由对应来源引擎决定，不能复用测速倒计时结束逻辑代替。

保存两类独立进度：Guided 的原生有效统计/恢复状态，Courses 的课程身份、内容版本、学习者类型、完成记录。可以共享记录容器和展示组件，但不得把课程练习直接喂入 Guided 计算；该联动无基准支持，V1 不做。

数据留在当前浏览器；不传逐键、课文、按键图谱给分析服务。保留原算法需要的逐键聚合历史，不自定截断窗口改变决策。原始事件仅用于当前轮与本地开发对照，用完释放。重复完成按 attempt ID 去重；跨标签更新须避免静默覆盖，UI 提示重新读取。存储失败时内存继续运行，但不得显示“已保存”。

进度结构、规则版本、课程版本分别标记。发现未来版本/损坏数据时提示不可读取并保留原值，提供用户主动重置；禁止自动将未知数据写成空进度。重置与测试历史清除分别执行。

## 7. 体验要求

路由保留 `/learn`、`/learn/practice`、`/learn/courses`、`/learn/courses/[lessonId]`，其中前两个独立路由作为兼容和直达入口。导航 Lessons 改为 Learn；不增加一级导航。`/learn` 打开即是持续练习，课程列表和说明内容按阅读顺序紧随其后。

沿用当前字体、留白、键盘提示与 Highlight 文字选中态；不使用白色色块作为选中背景。功能配置和运行状态集中在练习区顶部，避免四处分散；学习页不照搬测速倒计时。课程列表可见课次、学习键、完成/锁定状态；练习时重点显示文本与指法。

必须覆盖：首次进入、恢复、练习、暂停、完成、全部字母/课程已完成、存储不可用、无 JS、键盘布局不匹配以及未审查内容不可启动。来源与源码入口放在页面说明/页脚，不将实现细节挤进练习流程。

## 8. 质量与验收

- 规则一致性：上游与接入实现使用相同固定输入轨迹、设置、时钟与随机源；比较目标键、解锁、课程通过和关键统计。字串随机时验证范围及生成不变量，不用“看起来差不多”验收。
- 内容：无未教授字符、目标字符确实出现、ID 唯一、顺序与版本可追溯。所有最小修复有可读差异；原始审查失败仍保留。
- 浏览器：桌面 Chrome/Safari/Firefox/Edge，375/768/1280px 布局；键盘操作、焦点、读屏提示、刷新和跨标签更新；有输入兼容性限制时如实提示。
- 回归：现有测试引擎、计分、历史与时长路由行为不变；学习成绩不进入原 history。
- 发布：完整源码获取、许可证/素材权利、规则一致性、课程质量和主要旅程全部通过后才启用学习导航和生产发布。

## 9. 指标

先记录学习入口 → 开始 → 完成 → 继续的漏斗与模式区别，关注首次完成、继续练习、返回继续和课程卡点，不预设虚假的提升率。正式遥测延用现有同意门与属性白名单；只允许模式、动作、来源版本及区间化表现，不传目标键或原始统计。算法验证用的本地轨迹不是运营采集许可。
